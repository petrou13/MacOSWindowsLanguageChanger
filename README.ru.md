# MacOSWindowsLanguageChanger

[English](README.md) · **Русский**

Переключайте язык клавиатуры на Mac как в Windows — через **Shift + Command**, без переназначения Command и Option. Нативное приложение в строке меню для тех, кому нужно привычное переключение раскладки и работающие сочетания в Windows App / Remote Desktop.

**[Скачать версию 2.8](https://github.com/petrou13/MacOSWindowsLanguageChanger/releases/tag/v2.8)** · macOS 13+ · Apple Silicon и Intel · интерфейс на русском и английском

## Установка

1. Скачайте **PKG** из Releases, откройте его и следуйте шагам стандартного установщика macOS. Он установит приложение в «Программы». Альтернатива: распакуйте ZIP и самостоятельно перенесите приложение в «Программы».
2. Запустите MacOSWindowsLanguageChanger из «Программ». Откройте настройки через значок клавиатуры в строке меню.
3. В разделе **«Переключение»** выберите один режим доступа и нажмите **«Открыть настройки доступа…»**. Включите приложение в соответствующем списке конфиденциальности macOS. Оба разрешения одновременно не нужны.
4. Вернитесь в приложение. Если macOS требует перезапуск после выдачи доступа, завершите и снова откройте приложение.

Приложение подписано локально (ad hoc); PKG не подписан. У предварительной версии **нет подписи Developer ID и нотарификации Apple**. macOS может заблокировать первый запуск. Используйте [официальную инструкцию Apple](https://support.apple.com/102445), не отключая Gatekeeper.

## Возможности

- **Shift + Command**, **Option + Shift** или **Control + Shift**. Зажмите первую клавишу, затем вторую в любом порядке. Язык сменится после отпускания обеих; ограничения по времени удержания нет.
- Обычная клавиша, щелчок или прокрутка отменяют сочетание. Сочетания с буквой сохраняют обычное действие. Command и Option не переназначаются.
- Настраиваемое исключение RDP, включённое по умолчанию. Переключатель на паузе, пока Windows App / Microsoft Remote Desktop на переднем плане, и возобновляет работу при переходе в другое приложение.
- Выбор **русского или английского** в **«Основные → Язык интерфейса»**, без перезапуска. Выбор сохраняется. При первом запуске используется язык macOS, если он поддерживается, иначе английский. Язык интерфейса не меняет раскладку клавиатуры.
- Нативные настройки SwiftUI: «Переключение», «Строка меню», RDP, «Основные» и «О приложении». Нет запросов разрешений при запуске. Состояние доступа и раскрываемая диагностика находятся в настройках.
- Текущую раскладку в строке меню можно скрыть. Значок: SF Symbol, эмодзи или своё изображение. Светлая и тёмная темы, предпросмотр.
- Настраиваемый запуск при входе через SMAppService Apple.

## Один режим — одно разрешение

| Режим | Разрешение | Способ переключения |
| --- | --- | --- |
| Мониторинг ввода — базовый функционал | Мониторинг ввода | Напрямую выбирает источник ввода через TIS. Системный значок возле курсора может отставать. |
| Универсальный доступ — системное сочетание | Универсальный доступ | Отправляет настроенное системное сочетание macOS с полным нажатием и отпусканием модификаторов. |

Для системного режима должно быть включено сочетание выбора источника ввода в настройках клавиатуры macOS. Приложение только читает назначение и не меняет системные настройки.

### Работа с RDP

Исключение определяется по **активному приложению**, поэтому включает и локальные окна Windows App. Отдельные удалённые сеансы не анализируются. При включённом исключении меняйте язык на сервере его сочетанием или средствами Windows App. Приложение не переключает язык сервера самостоятельно. При отключении исключения работает переключение на Mac внутри Windows App; реакция сервера зависит от настроек клиента.

### Язык интерфейса и системные подписи

Язык приложения выбирается в «Основных». Названия источников ввода и стандартные диалоги macOS могут сохранять системный язык. Настройки, меню, сообщения о состоянии и диагностика приложения используют выбранный язык интерфейса.

## Приватность и проверки

Нет сетевых запросов, телеметрии, извлечения введённого текста или постоянных журналов клавиш. Для распознавания сочетания учитываются модификаторы и временный набор кодов удерживаемых клавиш: это предотвращает переключение при обычных сочетаниях. Исходные события возвращаются без изменений. Обновление раскладки выполняется по уведомлениям и короткой ограниченной серии проверок после переключения, без постоянного опроса.

Настройки и уменьшенная копия значка хранятся локально. Ограничения изображений: 10 МБ, 8192 пикселя по стороне и 32 мегапикселя. Подробнее: [проверки безопасности и ограничения](SECURITY.ru.md).

Автоматические проверки покрывают 60 000 циклов сочетаний, оба порядка клавиш, отмену при обычном вводе, выбор разрешений, некорректные системные сочетания и 15 полных комбинаций синтетических модификаторов. Русский и английский интерфейс и мгновенная смена языка проверены в работающем приложении. Эти проверки не покрывают все версии macOS, редакторы и реальные RDP-сеансы.

## Сборка из исходников

Нужны macOS, Xcode или Command Line Tools и принятая лицензия инструментов Apple. Сторонних зависимостей нет.

```sh
chmod +x build.sh package.sh
./build.sh       # регрессионные проверки, двуязычное универсальное приложение и ZIP
./package.sh     # стандартный установщик PKG и контрольные суммы SHA-256
```

`APP_SIGNING_IDENTITY` задаёт сертификат разработчика; по умолчанию подпись локальная. Подпись Developer ID, подпись установщика и нотарификация выполняются отдельно. Установщик содержит только приложение, без скриптов установки, и использует постоянный путь «Программы».

Используются SwiftUI/AppKit, Objective-C, Carbon и CoreGraphics. Локализация использует стандартные ресурсы `.lproj` и `.strings`, общие для Swift и Objective-C. Идентификатор приложения сохранён для совместимости настроек предыдущих версий.
