# Безопасность и проверки — 2.8

[English](SECURITY.md) · **Русский**

Это предварительная версия. Проверки снижают риск, но не гарантируют отсутствие всех дефектов.

## Область проверки

- В приложении нет сетевых клиентов, телеметрии, запуска внешних команд, загрузки кода или автоматических обновлений.
- Введённый текст не извлекается, журналы клавиш не записываются. Временные коды клавиш используются для отмены сочетания, если удерживается другая клавиша. Диагностические счётчики и последнее состояние хранятся в памяти.
- Базовый режим использует пассивный обработчик событий; системный — обработчик, разрешённый «Универсальным доступом». Все исходные события возвращаются без изменений. Системное сочетание отправляется только при распознанном переключении или явном нажатии кнопки переключения.
- Синтетические модификаторы полностью отпускаются. Перед отправкой проверяются физические модификаторы и активное приложение. Смена фокуса, пауза, изменение режима и сон отменяют ожидающие системные переключения.
- Исключение RDP включено по умолчанию и настраивается. Оно определяется по идентификатору активного приложения. При его отключении локальное переключение работает и в RDP.
- Изображения ограничены 10 МБ, 8192 пикселями по стороне и 32 мегапикселями. ImageIO сначала создаёт миниатюру, затем PNG 36×36; сохраняется только миниатюра.
- Приложение не выдаёт себе разрешения. Настройки доступа открываются только по явному действию пользователя. При запуске запросов доступа нет.
- Автозапуск настраивается через SMAppService Apple и по умолчанию выключен.
- Выбор языка интерфейса хранится локально и не меняет язык клавиатуры. В приложение включены двуязычные условия лицензии.

## Выполненные проверки

- Сборка arm64 / x86_64 для macOS 13+, строгие предупреждения компилятора для Objective-C и C.
- 60 000 циклов сочетаний: обычный ввод, оба порядка клавиш, отмена и отсутствие ограничения по времени.
- Чтение системного сочетания: произвольное назначение, порядок выбора, отключённые и некорректные настройки, отказ от модификатора или Power как основной клавиши.
- 15 комбинаций модификаторов: полное нажатие/отпускание и сохранение Caps Lock, без отправки событий в тестах.
- Каждый режим требует только своё разрешение.
- Русский и английский интерфейс, мгновенная смена языка, меню, сообщения о доступе, диагностика и сохранение выбора.
- Подпись приложения и содержимое установщика. PKG содержит только приложение, устанавливает его в «Программы», не содержит скриптов и не перемещает установку к старой копии в другом месте. Контрольные суммы SHA-256 опубликованы с файлами релиза.

## Ограничения

Приложение подписано локально, PKG не подписан; подписи Developer ID и нотарификации нет. Gatekeeper может заблокировать первый запуск. Не отключайте защиту macOS. После установки или обновления локально подписанной версии macOS может снова потребовать разрешение доступа.

Базовое переключение проверялось реальным вводом при разработке. Автоматические проверки не покрывают физическое Shift + Command во всех приложениях, все версии macOS или реальный сеанс рабочего сервера RDP. Значок возле курсора зависит от macOS и редактора; в базовом режиме он может отставать. Для системной индикации используйте системный режим.

Сообщайте о воспроизводимых ошибках через Issues, без паролей, рабочего текста, приватных адресов серверов и скриншотов с конфиденциальной информацией.
